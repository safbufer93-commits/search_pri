# ABCP Price Scanner (Excel → цены → Excel)

Этот проект берёт `.xlsx` с артикулами из папки `input/`, запрашивает предложения через **ABCP Public API** и создаёт файл результата в `output/`.

- Лист **Матрица**: к исходным колонкам добавляются новые колонки (поставщики). В ячейках — *минимальная цена* у этого поставщика по артикулу.
- Лист **Предложения**: все предложения списком (для контроля).
- Лист **Поставщики**: справочник «код → название» (как в панели ABCP).

## Что уже настроено
Внутри `.env` должны быть ваши параметры доступа из панели ABCP.

> ⚠️ Важно: `.env` содержит секреты. Не отправляйте его третьим лицам и не коммитьте в Git.

## Установка

1) Установите Python 3.10+  
2) Откройте терминал в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

## Как пользоваться

1) Положите ваш Excel в папку `input/`  
   - колонка с артикулами может называться: **Артикул / артикул / Article / Number / Номер** (или просто будет взята 1‑я колонка)
   - колонка бренда (необязательно): **Бренд / brand / Марка**

2) Запустите:

```bash
python price_scan_abcp.py --input input --output output --concurrency 6
```

3) Готовые файлы появятся в `output/` с суффиксом `_priced.xlsx`.

## Если API отвечает ошибкой (403/401/500)
Чаще всего причины такие:
- ваш IP не в белом списке API (нужно разрешить IP в настройках)
- неверный логин или md5‑пароль
- временные ограничения/фильтры у поставщиков онлайн

## Примечания по API
В разных установках ABCP метод поиска может быть доступен по разным путям.
Скрипт пробует:
- `/search/articles`
- `/cp/search/articles`

Также, чтобы в шапке Excel были **названия магазинов**, скрипт пытается получить справочник поставщиков через `GET /cp/distributors` (и несколько запасных путей).
